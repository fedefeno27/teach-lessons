AI Engineer: the course sequence

The Cambridge ICE AI Engineering Career Accelerator syllabus rebuilt from free and cheap courses, in the order to take them. About 12 months at about 10 hrs/week. Claude-specific items are marked in orange. Tick items off as you go; progress saves in this browser.

Phase 0 · Python and the plumbing

Weeks 1–8

Replaces Cambridge's "Foundations". Write this phase by hand, without Claude Code writing it for you, because interviews test whether you can read and debug code.

  1. CS50P: Introduction to Programming with Python
    Harvard · 10 lectures + problem sets + final project

    The Python foundation. Do every problem set, because they are the course. Your JS background makes it faster.

    FreeCore
  2. The Missing Semester of Your CS Education
    MIT · take the shell, Git and debugging lectures

    Terminal, Git and debugging: the plumbing every engineering job assumes you have.

    Free
  3. SQLBolt
    Interactive SQL lessons · a few evenings

    Enough SQL to run a Postgres vector store in Phase 1.

    Free
  4. Claude Platform 101
    Anthropic Academy

    Building on the Claude Platform from scratch: API keys, models, the Console, first calls.

    ClaudeFreeCore
  5. Building with the Claude API
    Anthropic Academy · the main Claude course

    The full spectrum of the Claude API: messages, system prompts, structured output, tool use, streaming, RAG and agents. It replaces most of the Udacity nanodegree for free.

    ClaudeFreeCore
  6. Prompt Engineering Interactive Tutorial
    Anthropic · GitHub notebooks · also see prompt engineering docs

    Hands-on prompting exercises: clear instructions, examples, XML structure, chaining, avoiding hallucination.

    ClaudeFree
  7. Claude docs: Tool use
    Anthropic docs · plus anthropics/courses (the tool-use notebooks)

    How Claude calls your functions. It's the building block for everything in Phases 1–2.

    ClaudeFree
  8. AI Engineering: Chip Huyen (O'Reilly, 2025)
    Book · read one chapter a fortnight across the whole year

    The closest single text to the Cambridge syllabus: foundation models, evaluation, RAG, agents, fine-tuning, inference cost. Your textbook for the year.

    ~£45Core
Exit test: a Python command-line tool that calls Claude, uses one tool, and has three pytest tests. Push it to GitHub.

Phase 1 · RAG and your Claude Code workflow

Weeks 9–18

Cambridge Module 1: RAG and retrieval architecture. Claude Code becomes your daily tool from here on.

  1. Claude Code 101
    Anthropic Academy · reference: Claude Code docs

    Using Claude Code effectively day to day. Quick for you, since you already ship with it. It fills the gaps.

    ClaudeFree
  2. Claude Code in Action
    Anthropic Academy

    Long, hands-off sessions you can trust: steering, configuration, hooks, automation, verification.

    ClaudeFree
  3. Claude Code: Software Engineering with Generative AI Agents
    Vanderbilt University · Jules White · Coursera · about 5 hrs · 4.7★

    Running Claude Code like a tech lead: parallel workflows, "best of N", automated test suites, context management. Complements Anthropic's two courses above.

    ClaudeFree to audit
  4. AI Hero: AI Coding Crash Course (Matt Pocock)
    Already purchased · the basis of index.html in this folder

    Finish it here. It's your engineering-discipline layer: planning, TDD, and small verifiable steps with Claude Code. It's TypeScript, so it keeps your front-end strength sharp.

    ClaudeOwned
  5. Retrieval Augmented Generation (RAG)
    DeepLearning.AI

    The main RAG course: embeddings, chunking, vector databases, hybrid search, re-ranking, production concerns.

    Free (audit)Core
  6. Introducing Contextual Retrieval
    Anthropic engineering article · code in Claude Cookbooks: RAG

    Anthropic's RAG technique (contextual embeddings + contextual BM25 + re-ranking). Work through the cookbook notebook alongside it.

    ClaudeFree
  7. Building and Evaluating Advanced RAG
    DeepLearning.AI short course · about 1 hr

    Advanced retrieval and your first RAG metrics: context relevance, groundedness, answer relevance.

    Free
  8. FastAPI Tutorial + pgvector
    Official docs · setup with uv

    The back end you'll build Project 1 on: a Python API plus Postgres with vector search.

    Free
Project 1: "Ask the Manual". RAG over public product manuals (e-bikes, folding bikes, power tools). Page-level citations, and it refuses when the docs don't cover the question. Python + FastAPI + pgvector + Claude, with your own web front end. Deploy it.

Phase 2 · Agents, MCP and multi-agent systems

Weeks 19–28

Cambridge Module 2. Learn it from first principles (Stanford), then with Claude's own tools, then with frameworks.

  1. Building Effective Agents
    Anthropic engineering article · code in Claude Cookbooks: agent patterns

    Read this first. Workflows (chaining, routing, parallelisation, orchestrator-workers, evaluator-optimiser) before autonomous agents. Explains when not to use an agent.

    ClaudeFreeCore
  2. CS329Z: Engineering AI Agents
    Stanford · Fall 2026 · 17 lectures, 2 homeworks, about 50 readings

    The core of this phase. Build RAG, tool use and agent loops with no framework, then see how frameworks abstract them. Graded on design decisions and evals, not recall. Do both homeworks.

    Free (public materials)Core
  3. Introduction to Model Context Protocol
    Anthropic Academy · reference: modelcontextprotocol.io

    Build MCP servers and clients from scratch in Python: tools, resources, prompts.

    ClaudeFreeCore
  4. Model Context Protocol: Advanced Topics
    Anthropic Academy

    Sampling, notifications, file-system access, transports: what production MCP servers need.

    ClaudeFree
  5. Writing Effective Tools for Agents · Effective Context Engineering
    Anthropic engineering articles

    Tool design and context management. Two of the five domains of Anthropic's architect certification.

    ClaudeFree
  6. Claude Agent SDK
    Anthropic docs

    The harness behind Claude Code, available to you: agent loop, tools, permissions, subagents, sessions. Use it for Project 2.

    ClaudeFreeCore
  7. How We Built Our Multi-Agent Research System
    Anthropic engineering article

    A real production multi-agent case study: orchestrator + subagents, token cost, evaluation, failure modes.

    ClaudeFree
  8. Introduction to Subagents · Introduction to Agent Skills
    Anthropic Academy · two short courses

    Delegating to specialised subagents and packaging reusable skills. These are multi-agent patterns in practice.

    ClaudeFree
  9. Hugging Face Agents Course
    Hugging Face · 4 units, about 15–20 hrs · free certificate

    The framework layer: smolagents, LlamaIndex, LangGraph, agentic RAG, and a benchmarked final challenge. Covers LangGraph, so no separate LangGraph course is needed.

    Free + certificateCore
Project 2: design-review agent. Built on the Claude Agent SDK plus your own MCP server. It takes a spec or BOM (public or invented), checks part count, materials, standards and cost targets, cites its sources, and waits for human approval before acting.

Phase 3 · Evaluation and LLMOps

Weeks 29–36

Cambridge Module 3. This is where your product judgement becomes an engineering skill: evals are quality specifications.

  1. Your AI Product Needs Evals · A Field Guide to Rapidly Improving AI Products
    Hamel Husain · articles

    Error analysis first, metrics second. The most practical eval thinking available for free.

    FreeCore
  2. Define Success Criteria · Create Strong Empirical Evaluations
    Anthropic docs

    Anthropic's method for writing measurable criteria and building eval sets, including grading with Claude as the judge.

    ClaudeFree
  3. Evaluating AI Agents
    DeepLearning.AI × Arize · short course

    Tracing, evaluating each step of an agent, LLM-as-judge, running experiments to improve it.

    FreeCore
  4. Langfuse or Arize Phoenix
    Open-source observability · pick one

    Traces, cost and latency dashboards, datasets and experiments. Wire it into both projects.

    Free (self-host / free tier)
  5. LLM Bootcamp
    Full Stack Deep Learning · take the deployment and LLMOps lectures

    Deployment and ops fundamentals. It's from 2023, so the tooling is dated, but the principles still hold.

    FreeOptional
Upgrade both projects: a golden test set labelled by you, an LLM judge checked against your labels, regression evals in GitHub Actions, tracing, and a cost/latency dashboard. Dockerise and deploy.

Phase 4 · Security, governance and cost

Weeks 37–42

Cambridge Modules 4 and 5. The recommended list you were sent had nothing for these.

  1. OWASP Top 10 for LLM Applications
    OWASP GenAI Security Project

    Prompt injection, sensitive-data leakage, excessive agency, and more. The industry-standard risk list.

    FreeCore
  2. Red Teaming LLM Applications
    DeepLearning.AI × Giskard · short course

    Attack your own apps systematically. Then red-team Project 2 and write up the findings and fixes.

    Free
  3. Prompt Caching · Batch Processing · Choosing a Model
    Anthropic docs

    The three biggest cost levers on Claude: cache repeated context, batch non-urgent work, route easy tasks to cheaper models. Show cost per 1,000 queries before and after.

    ClaudeFreeCore
  4. Lead With the Number (your own lesson)
    Head of Design course · Lesson 01

    Cambridge's "stakeholder communication": write a one-page decision memo for a non-technical exec, with the number first.

    Free

Considered and skipped

  • Udacity: AI Engineering with Claude: $999 or $249/month for about 38 hrs. Anthropic Academy covers the same ground (API, Claude Code, Agent SDK, MCP) for free. Worth it only at a steep discount if you want human project reviews.
  • DeepLearning.AI: AI Agents in LangGraph: already covered by the Hugging Face Agents Course. Take it only if a job ad asks for LangGraph.
  • IBM RAG and Agentic AI Professional Certificate: 9–10 courses, heavy on LangChain, needs a Coursera subscription. Phase 1 covers RAG more directly.

From your "Ai course" bookmarks

  • Python for Everybody (Michigan): a good course, but pick one Python course. CS50P is harder and more engineering-focused, which suits someone who already writes JS. Use PY4E only if CS50P feels too steep.
  • Claude Code in Action (Coursera): the same Anthropic course as the free Anthropic Academy version in Phase 1. Coursera charges for the certificate.
  • Real-World AI with Claude: Anthropic + AWIT, aimed at non-technical professionals. Below your level.
  • Mastering Claude AI (Edureka): 3.8★ from 29 reviews. Anthropic's own free API and MCP courses cover the same topics better.
  • Advanced Multi-Agent AI System: 3 hrs, no named institution, AI-graded. CS329Z + Anthropic's multi-agent material go much deeper.
  • AI Engineering (Scrimba): 9 courses, about 20 hrs, in JavaScript. Tempting given your JS, but built around OpenAI, and parts are dated (Assistants API, DALL·E). Optional warm-up at most.
  • IBM Generative AI Engineering: 16 courses, about 6 months. Well rated, but it's the ML-engineer path (PyTorch, Keras, fine-tuning transformers), not the product AI-engineer path this plan targets.
  • Udacity MSc in AI (Woolf University): about $5,000, about 2,250 hours, about 25 hrs/week. Cambridge-level cost, and the hours don't fit alongside a full-time job.
  • AI Engineering from Scratch: free and open source, but 523 lessons from linear algebra up. Use it as a reference to dip into, not as a course to follow.
